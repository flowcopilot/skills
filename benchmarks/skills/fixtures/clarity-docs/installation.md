# Install Field Notes CLI

The installation process is something that should be undertaken once Node.js 22 or later is present on the machine. In order to get things up and running, the command npm install --global @field-notes/cli needs to be executed in a terminal. An account must have already been created at https://accounts.example.test before login can take place. After installation has been completed, field-notes login is the command that opens a browser where the user signs in with that account. Once that has been done, field-notes init needs to be run from the project directory, where it creates field-notes.json. It is important to note that field-notes.json should be committed to version control, but the .field-notes/token file should never be committed because it contains the login token. The installation can be checked by running field-notes doctor, which prints Ready when the setup is correct. If the command is not found after installation, reopen the terminal and try again.
